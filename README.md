# 🇬🇧 English A1

**British English — курс A1.** 12 недель британского английского для русскоязычных: от алфавита и звуков до финального экзамена A1, по методу Фейнмана. Сделан по образцу [Portuguese by Feinman](https://github.com/vpresweb/Portuguese-by-Feinman).

> Понял — объясни ребёнку. Не можешь объяснить — значит, не понял.
> Пробел в объяснении = следующая тема для изучения.

Онлайн: https://vpresweb.github.io/English_A1/

## Что внутри

| Неделя | Тема |
|:-----:|------|
| 1 | Знакомство · Звуки · Алфавит |
| 2 | Числа · Время · Семья |
| 3 | Present Simple · Распорядок дня |
| 4 | Еда · Покупки |
| 5 | Дом · Мебель |
| 6 | Город · Транспорт |
| 7 | Одежда · Present Continuous |
| 8 | Тело · Здоровье |
| 9 | Погода · Прошлое |
| 10 | Работа · Модальные · Планы |
| 11 | Хобби · Сравнения · Мнения |
| 12 | Финал A1 · Экзамен |

В каждой неделе есть план по дням, словарь с британской транскрипцией (IPA) и переводом, грамматика с объяснением «по Фейнману», диалог, тест с разбором ответов и «дневник Фейнмана». В дневнике вы объясняете тему своими словами и получаете подсказки. Неделя 12 — финальный экзамен: грамматика, лексика, письмо, говорение с самооценкой, итоговый результат и дорожная карта до A2 Key.

- 🔊 **Озвучка.** Нажмите на любой английский текст (слово, пример, реплику, карточку), и браузер произнесёт его британским голосом `en-GB`, если он есть, иначе американским (Web Speech API).
- 💾 **Прогресс.** Ответы тестов, отмеченные дни плана и тексты дневника сохраняются в браузере (`localStorage`). Недели с пройденным тестом (от 60%) отмечаются ✓.
- 📱 **PWA.** На iPhone или Android сайт можно добавить на главный экран как приложение.
- ⚡ **Без сборки и зависимостей.** Чистые HTML, CSS и JavaScript. Из сети грузятся только шрифты Google Fonts.

## Запуск

```bash
git clone https://github.com/vpresweb/English_A1.git
cd English_A1
python -m http.server 8000
# откройте http://localhost:8000
```

Можно просто открыть `index.html` двойным кликом: скрипты подключены без модулей. Иконка приложения (манифест) работает только через HTTP-сервер.

## Структура

```
index.html             — каркас страницы: шапка, панель недель, подвал
css/styles.css         — дизайн-система
js/core.js             — хранилище прогресса, переключение недель и вкладок, озвучка speak()
js/week-01.js … 12.js  — содержание недель (данные)
js/render.js           — сборка страниц из данных и интерактив: тесты, дневник, план, итог
manifest.webmanifest   — манифест PWA
icons/icon.svg         — иконка приложения
tests/                 — автотесты (node --test)
```

### Формат недели

Каждая неделя — объект в `COURSE.weeks` со списком вкладок, вкладка — со списком блоков:

```js
COURSE.weeks.push({
  n: 3,
  title: 'Present Simple · Распорядок дня',
  tabs: [
    { id: 'routine', label: '🕗 Распорядок', blocks: [
      { t: 'label', text: 'Daily routine' },
      { t: 'grid', items: [{ icon: '⏰', en: 'wake up', ipa: '[weɪk ʌp]', ru: 'просыпаться', ex: 'I wake up at 7.' }] },
      { t: 'card', color: 'blue', title: 'Have — не только «иметь»', html: '<p><span class="en">have breakfast</span> — завтракать</p>' },
    ] },
    { id: 'quiz', label: '🎯 Тест', blocks: [
      { t: 'quiz', items: [{ q: 'She ___ in a bank.', opts: ['works', 'work', 'working', 'is work'], ans: 0, exp: 'He / she / it → <em>-s</em>.' }] },
    ] },
  ],
});
```

Типы блоков: `label`, `card`, `steps`, `sounds`, `vocab`, `grid`, `flip`, `numbers`, `dialogue`, `table`, `compare`, `exercise`, `journal`, `writing`, `quiz`, `plan`, `summary`, `roadmap`, `selfcheck`, `result`. Английский текст внутри HTML помечается `<span class="en">…</span>` — такой текст озвучивается по нажатию.

## Тесты

```
npm test
```

Проверяется структура всех недель, корректность вопросов (4 варианта, верный ответ, пояснение), равномерное распределение правильных ответов по вариантам, обратная связь у заданий, парность HTML-тегов. Тесты запускаются в GitHub Actions при каждом push в `main`.
